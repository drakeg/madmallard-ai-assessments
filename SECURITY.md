# Security policy

This is a pre-release, LAN-only development prototype. Do not expose the dashboard publicly or use real client data until authentication, authorization and retention controls are implemented.

Report vulnerabilities privately to repository maintainers via GitHub's private vulnerability reporting where enabled. Do not post credentials, customer activity, or exploit details in public issues.

See [docs/SECURITY.md](docs/SECURITY.md) for assessment consent and safe testing requirements.
